## 확인 범위

- 동일 커밋의 equipment.json 전체 종류에 대해 node와 transfer_node를 모두 제외했다.
- 동일 커밋 oht_lot_schedule.json의 20,000개 로트에서 stk_node, eq_node, stb_node를 대조했다. 선정 노드 3개 모두 포함 횟수 0이다.
- 시뮬레이터의 작업 생성은 이 포트 노드를 출발/도착지로 사용한다. 다른 시드라도 동일 포트 목록에서 생성하면 이 일반 노드가 상하차 목적지로 선택되지는 않는다. 지도·포트 목록 또는 스케줄 형식이 바뀌면 재검증해야 한다.
- 이 분석은 상하차 목적지가 아니라는 뜻이며, 실제로 차량이 얼마나 통과하는지 또는 유휴 대기 지점으로 쓰이는지까지 검증한 것은 아니다. 호이스팅 대상은 적재 작업 차량의 경로상 방문으로 제한할 계획이다.
- 진입·진출 링크 각각 1개, 방향 변화 10도 이하, 인접 링크가 곡선이 아니며 합류 구역 분류가 없는 노드를 조사했다.
- 위 조건을 만족하는 일반 노드는 913개다. 선로를 따라 양쪽 첫 분기·합류·곡선 경계까지 3m 이상인 후보는 296개이며, 지도 중앙부인 중앙통로 2에는 82개가 있다.
- 82개 중 최소 양방향 여유 거리가 큰 순서로 선택하되 후보 간 지도상 간격 15m를 두어 3개 지점을 골랐다. 10도·3m·15m는 분석용 선별 기준이지 설치 규격이 아니다.
- 옆 차선에 있는 합류부까지의 직선거리가 아니라, 해당 차선의 진행/역진행 방향으로 계산한 링크 길이 합을 사용했다.
- 기존 물리적 버퍼가 있다는 주장이 아니라 **일반 주행 노드에 가상 호이스팅 정지 효과를 추가하는 실험 위치**다. 실물 설치 공간은 검증하지 않았다.
